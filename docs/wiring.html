六路舵机接线图（3×20kg + 3×MG90S）

电脑 → USB → Arduino UNO →(I2C)→ PCA9685 → 6 个舵机；舵机电源走电源分配板 5V（测试可用，重载需换大电流电源）。
🔌 关于用分配板的 5V：电压安全，桌面空载测试 OK。但分配板 5V 一般只有 2~3A， 3 个 20kg 带负载/同时使劲会电流不够 → 舵机抖、UNO 重启、板子保护断电。 真要带负载用，请换独立 5~6V / ≥10A 开关电源接 V+。绝不能接 12V。
连接从到线色(图中)
I2C 时钟UNO A5/SCLPCA9685 SCL绿
I2C 数据UNO A4/SDAPCA9685 SDA蓝
芯片逻辑电源UNO 5VPCA9685 VCC红
逻辑地UNO GNDPCA9685 GND黑
舵机电源 +分配板 +5VPCA9685 V+ 端子绿(5V)
舵机电源 −分配板 GNDPCA9685 GND 端子（并与 UNO 共地）黑
20kg 舵机 ①②③各 3 线插头PCA9685 CH0 / CH1 / CH2棕GND/红V+/橙信号
MG90S ④⑤⑥各 3 线插头PCA9685 CH3 / CH4 / CH5棕GND/红V+/橙信号
🔧 插舵机：每路 3 针丝印 PWM / V+ / GND，舵机线 橙(信号)→PWM、红→V+、棕→GND，插反舵机不动会发热。
通道 0 在靠近 SCL/SDA 控制排针那一端，依次 0→5。I2C 地址默认 0x40。 UNO、PCA9685、电源分配板三者 GND 必须共地。
